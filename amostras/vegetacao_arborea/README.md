
# Banco de amostras — Vegetação arbórea

## Projeto CBERS-4A — Carine

Esta pasta reúne as amostras da classe Vegetação arbórea, obtidas a partir de imagens de sensoriamento remoto CBERS-4A.

As amostras são identificadas por meio de polígonos anotados no CVAT e utilizadas nos experimentos de classificação com a rede neural MobileNetV2.

## Classe
Vegetação arbórea

## Arquivos
Serão armazenadas nesta pasta imagens de pré-visualização das amostras, preferencialmente em formato PNG.

Os arquivos GeoTIFF originais permanecem preservados no Google Drive.

## Atualizações
Novas amostras serão adicionadas conforme o desenvolvimento da pesquisa.
