
# Arquivos gerados — Tabelas

## Projeto CBERS-4A — Carine

Esta pasta reúne tabelas produzidas durante o processamento das imagens, extração de amostras e execução dos experimentos.

## Exemplos de tabelas
- Quantidade de patches por dimensão.
- Percentual de pixels NoData.
- Quantidade de polígonos por classe.
- Distribuição das amostras em treinamento, validação e teste.
- Resultados das classificações.
- Métricas de avaliação dos modelos.

## Formato
Preferencialmente CSV.

## Objetivo
Permitir a consulta, conferência e comparação dos dados utilizados na pesquisa.
