
# Arquivos gerados — Visualizações

## Projeto CBERS-4A — Carine

Esta pasta reúne imagens e visualizações produzidas durante o processamento dos dados CBERS-4A.

## Exemplos de arquivos
- Composições RGB e falsa-cor NIR.
- Visualizações de patches.
- Imagens de comparação entre métodos de recorte.
- Imagens de conferência de polígonos.
- Outras visualizações produzidas no Google Colab.

## Formato
Preferencialmente PNG.

## Observação
As imagens desta pasta são produtos de visualização e não substituem os dados originais armazenados em GeoTIFF.
