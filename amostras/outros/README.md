
# Banco de amostras — Outros

## Projeto CBERS-4A — Carine

Esta pasta reúne as amostras da classe Outros, utilizada no sistema de classificação binária do projeto.

## Classe
Outros

Esta classe contempla elementos que não pertencem à classe Vegetação arbórea, incluindo superfícies construídas, vegetação rasteira, solo exposto e superfícies impermeáveis.

## Arquivos
Serão armazenadas nesta pasta imagens de pré-visualização das amostras, preferencialmente em formato PNG.

Os arquivos GeoTIFF originais permanecem preservados no Google Drive.

## Atualizações
Novas amostras serão adicionadas conforme o desenvolvimento da pesquisa.
